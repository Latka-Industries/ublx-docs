# Writing

The **Writing** tab shows **word and character statistics** when ZahirScan extracted them for the selected file.

Focus with **w**.

## What fills the pane

| Stat | Typical sources |
|------|-----------------|
| Word / character counts | Prose documents, markdown, plain text |
| Footprint summaries | [Writing footprint](/zahirscan/templates/writing-footprint) mining |

If the file type does not produce writing stats, the tab may be empty or minimal.

## When data appears

Requires enhanced snapshot JSON (not path-only). Use **Enhance with ZahirScan** (**z** in quick actions) or batch/policy enhance — [Path-only vs full enhance](/guides/path-only-vs-full-enhance).
