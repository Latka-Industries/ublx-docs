# Guides

Cross-tool workflows for the catalog stack.

## Planned guides

- **Path-only vs full enhance** — when to batch ZahirScan and when to enrich on demand
- **Headless snapshot + export** — `ublx --snapshot-only --export` pipelines
- **Enhance policies** — scoping ZahirScan with `[[enhance_policy]]`

::: tip Tetration integration
Reading or exporting [`.tet` tensor stores](https://github.com/Latka-Industries/tetration-docs) is covered on the Tetration docs site. ZahirScan can extract metadata from `.tet` files in a UBLX catalog.
:::
