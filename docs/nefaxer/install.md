# Install

## Library

```bash
cargo add nefaxer
```

## CLI

```bash
cargo install nefaxer
```

## From source / releases

```bash
git clone https://github.com/Latka-Industries/nefaxer.git
cd nefaxer
cargo install --path .
```

Release archives: [GitHub Releases](https://github.com/Latka-Industries/nefaxer/releases).
